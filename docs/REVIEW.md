# گزارش تحویل نسخهٔ React / Django اخوت

یادداشت نسخهٔ استقرار: این گزارش، مبنای تحویل پیش از افزودن Docker بود. اکنون Dockerfile، Redis داخلی و بررسی سلامت دارکوب اضافه شده‌اند. جزئیات و محدودیت‌های نسخهٔ جدید در [DARKUBE.md](DARKUBE.md) آمده است. زیپ قبلی تغییر نکرده است.

تاریخ بررسی: ۲۳ نوامبر ۲۰۲۶. محدوده: بازنویسی بستهٔ قبلی در پوشهٔ مستقل `okhovat-react-django`، بدون تغییر ZIP قبلی و بدون ساخت Docker image یا ZIP جدید.

## آنچه پیاده‌سازی شده

- React + TypeScript، React Router و Framer Motion؛ صفحات خانه، ورود، پروفایل، رشد، پست، ساخت پست، دستیار، اعلان، نظارت مربی و مدیریت.
- لوگوها و تصاویر قبلی و stylesheet اصلی منتقل شده‌اند. RTL، رنگ روشن/تاریک، کپسول ناوبری، لودینگ، ورود نرم کارت‌ها، تایپ خوش‌آمد و راهنمای اولین ورود وجود دارند.
- APIهای Django/DRF و مدل‌های PostgreSQL، migration نسخه‌بندی‌شده، JSONB و کلیدهای خارجی. شروع برنامه حساب یا جدول مخفی نمی‌سازد.
- ستون‌های مستقل مربی، ادمین، مسئول حلقه، مسئول کارگروه و عضو دغدغه‌مند در User. یک نفر می‌تواند چند نقش داشته باشد؛ ادمین بودن به‌تنهایی پست را طلایی نمی‌کند.
- رمز فقط به صورت هش Argon2 در ستون password؛ سازگاری موقت با هش scrypt قبلی و ارتقا پس از ورود. حساب تستی یا رمز پیش‌فرض در برنامه ساخته نمی‌شود.
- گزارش رشد خصوصی با انتخاب انتشار خلاصه در پست‌ها؛ گزینهٔ انتشار پیش‌فرض خاموش است. ویرایش گزارش روزانه رکورد تکراری نمی‌سازد.
- پست، پیوست، لایک، دیدگاه و پاسخ، دنبال‌کردن، ذخیره و پیشنهاد به مربی، پست مربی طلایی، حذف ادمین و تعلیق یک/سه‌روزه.
- پروفایل با باکس آمار، خروج آیکونی، حضور خود و هم‌حلقه‌ای‌ها، برنامه/کتاب، پیام مربی و امتیاز/رده‌بندی حلقه.
- نظارت مربی: انتخاب فرد، گزارش هفت روز اخیر، برنامه و جلسهٔ ثبت‌شده، نمودار و فیلترهای جمعی، پیام به همه/کارگروه/حلقه/فرد و آرشیو.
- مدیریت: ساخت عضو واقعی، تغییر نقش‌ها و عضویت، گزارش هفتگی ثبت رشد/افراد بدون ثبت و تعداد برنامه‌ها و جلسه‌ها، خروجی CSV.
- محتوای کارگروه و فرم سفارشی با ذخیرهٔ واقعی؛ دستیار راهنما و آمار محدود به خود کاربر/حلقه، اتصال اختیاری به Ollama برای تفسیر سؤال.
- کش Redis با TTL پانزده دقیقه و ابطال هنگام تغییر؛ نشست هفت‌روزهٔ مستقل از Redis. API خصوصی در مرورگر کش نمی‌شود.
- راهنمای نصب Windows/Linux، استقرار بدون Docker، انتقال read-only از منبع قدیمی به دیتابیس تازه، بازیابی رمز با ورودی مخفی و راهنمای دیسک دائمی فایل‌ها.

## نتیجهٔ بررسی‌ها

| بررسی | نتیجه و محدوده |
|---|---|
| تست بک‌اند | ۱۷ سناریو؛ CSRF، ورود، هش و ارتقا، مجوز نقش، مالکیت، انتشار اختیاری، حذف، پیام، کش، تعلیق، فایل خصوصی، ورودی نامعتبر، لایک/دیدگاه، ضریب رتبه و محدودیت دادهٔ دستیار |
| تست رابط | ۴ تست برای آمار پروفایل، خروج، انتشار پیش‌فرض خاموش، حفظ انتخاب انتشار و انتخاب‌گرهای مربی |
| ساخت فرانت | TypeScript و Vite build موفق |
| سازگاری مدل/migration | `makemigrations --check --dry-run`: بدون تغییر جاافتاده |
| وابستگی Python | pip-audit برای ۲۶ وابستگی قفل‌شده: صفر آسیب‌پذیری شناخته‌شده در زمان بررسی |
| وابستگی اجرایی فرانت | `npm audit --omit=dev`: صفر آسیب‌پذیری شناخته‌شده در زمان بررسی |
| PostgreSQL/Redis واقعی | اجرا نشده؛ محیط جاری اجازهٔ راه‌اندازی socket سرویس محلی را نداد. تست‌ها از SQLite حافظه‌ای/کش حافظه‌ای ایزوله استفاده کردند |
| آزمون دیداری مرورگر | اجرا نشده؛ سرویس پیش‌نمایش در دسترس نبود. تطبیق پیکسل‌به‌پیکسل با نسخهٔ قبلی تأیید نشده است |

این جدول شرح کنترل‌های پیاده‌شده است، نه گواهی امنیت یا تضمین مصونیت از همهٔ حمله‌ها.

| دسته | کنترل مرتبط در کد | مورد عملیاتی باقی‌مانده |
|---|---|---|
| A01 کنترل دسترسی | مجوز سمت API، بررسی مالکیت فایل/گزارش، محدودیت مربی/ادمین، جلوگیری از ارتقای نقش توسط کاربر | آزمون نقش‌های واقعی در staging |
| A02 پیکربندی ناامن | DEBUG خاموش تولید، hosts صریح، HTTPS، هدرها، فایل خصوصی | تنظیم دامنه، پراکسی مورد اعتماد، فایروال و secrets |
| A03 زنجیرهٔ تأمین | requirements نسخه‌ثابت و package-lock، بررسی آسیب‌پذیری | audit دوره‌ای و بررسی تغییر وابستگی‌ها |
| A04 رمزنگاری | Argon2، کوکی Secure/HttpOnly، عدم نگهداری رمز در فرانت | TLS دیتابیس/Redis و حفاظت backup مطابق میزبان |
| A05 تزریق | ORM و ورودی‌های محدود serializer، escaping پیش‌فرض React، CSP | عدم افزودن SQL خام/HTML خام در توسعهٔ بعدی |
| A06 طراحی ناامن | گزارش خصوصی پیش‌فرض، جداسازی نقش‌ها، سهمیهٔ فایل، انتقال تراکنشی، آخرین ادمین محفوظ | تعیین سیاست نگهداری داده و بررسی فرایندهای سازمان |
| A07 احراز هویت | CSRF حتی ورود، محدودیت IP/حساب، پیام عمومی خطای ورود، انقضای نشست، بازیابی کنترل‌شده | احراز هویت پشتیبانی قبل از reset؛ MFA هنوز پیاده نشده |
| A08 تمامیت داده/نرم‌افزار | FK و constraint، تراکنش، ورودی اضافه ردشده، JSON به جای deserialization ناامن | حفاظت Git/CI، دسترسی migration و بکاپ |
| A09 لاگ و هشدار | AuditEvent و لاگ ورود/تغییر نقش/حذف، request ID، حذف رمز و بدنه از access log | اتصال پایش و هشدار میزبان؛ لاگ اپ به‌تنهایی سامانهٔ هشدار نیست |
| A10 خطاهای استثنایی | timeout، محدودیت حجم، ۵۰۳ کنترل‌شده، rollback، fallback دستیار/حضور | تست قطعی خدمات و load test روی منابع واقعی |

`SECURE_HSTS_PRELOAD=False` عمداً حفظ شده است؛ ثبت دامنه در فهرست preload تصمیم عملیاتی جداگانه است. به همین علت `check --deploy` می‌تواند هشدار W021 بدهد. کنترل clickjacking هم با middleware استاندارد Django و هم CSP اعمال می‌شود.

## مواردی که نباید فعال/تأییدشده فرض شوند

- انتقال واقعی داده و فایل‌های قبلی، اتصال شیت خصوصی و تست درصد حضور روی اطلاعات زنده هنوز نیازمند اجرای staging با تنظیمات خودت است.
- ریلز طبق درخواست قبلی همچنان «به‌زودی» است؛ صفحهٔ اجرایی انتشار ریلز ساخته نشده است.
- شناسهٔ بله در User و پنل مدیریت قابل ذخیره است، اما ارسال یادآوری شبانهٔ بله و ربات متصل در این بسته فعال نیست. آن قابلیت در بک‌اند بستهٔ مبنا نیز وجود نداشت؛ به توکن ربات، شناسه‌های معتبر و زمان‌بند سرور نیاز دارد.
- مصوبات مستقل و تحلیل کلیک/رفتار کاربر، که در گفتگوهای قبلی مطرح شده بودند ولی در schema عملی بستهٔ مبنا نبودند، در این مهاجرت اضافه نشده‌اند. هیچ دادهٔ نمایشی جای آن‌ها گذاشته نشده است.
- بازیابی خودکار رمز با پیام‌رسان/ایمیل فعال نیست؛ تماس پشتیبانی و reset امن سمت سرور وجود دارد.
- معماری PostgreSQL تنظیم شده، اما «آمادهٔ انتشار قطعی» بدون تست شبکه، migration واقعی، دیسک، HTTPS، بازیابی پشتیبان و مقایسهٔ دیداری اعلام نمی‌شود.

## ادامهٔ تحویل

ZIP قدیمی دست‌نخورده است. ساخت ZIP جدید طبق درخواست کاربر منوط به اجازهٔ او پس از این گزارش است. بستهٔ نهایی باید سورس، assets، lockfileها، migrationها و راهنما را داشته باشد؛ `.env` واقعی، node_modules، venv، فایل کاربران، دیتابیس و کلیدها نباید داخل آن باشند.
