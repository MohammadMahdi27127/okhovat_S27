# قرارداد API

همهٔ مسیرها زیر `/api/` و با slash پایانی‌اند. ابتدا `GET session/` را بخوان؛ csrf پاسخ را برای درخواست نوشتنی در `X-CSRFToken` بفرست و cookie نشست را حفظ کن. login هم CSRF لازم دارد. فرانت رسمی این کار را انجام می‌دهد. ورودی JSON است؛ فقط upload از multipart استفاده می‌کند. ورودی اضافی شناخته‌نشده رد می‌شود.

| مسیر | متد | دسترسی و نتیجه |
|---|---|---|
| session/ | GET | عمومی؛ کاربر جاری، CSRF و حضور آخرین ورود |
| login/, logout/, password/ | POST | ورود؛ خروج؛ تغییر رمز با رمز فعلی |
| state/ | GET | دادهٔ مجاز کاربر، آمار پروفایل، فرم‌ها، پیام‌ها و فهرست لازم برای نقش |
| growth/ | PUT | فقط گزارش خود عضو؛ یک گزارش در هر روز؛ publish پیش‌فرض false |
| posts/ | GET, POST | اعضای واردشده؛ صفحه‌بندی ۳۰تایی و ثبت پست |
| posts/?tab=trending | GET | پیشنهادهای اعضا به مربی، قابل مشاهده برای اعضا |
| posts/?id=ID | GET | پست مشخص برای لینک اشتراک‌گذاری |
| posts/ID/ | DELETE | فقط ادمین؛ حذف از نمایش و حفظ سابقهٔ مدیریتی |
| posts/ID/votes/KIND/ | PUT | active: true/false؛ like، recommend یا bookmark |
| posts/ID/comments/ | GET, POST | دیدگاه؛ پاسخ حداکثر یک سطح |
| comments/ID/like/ | PUT | پسند دیدگاه |
| follows/CODE/ | PUT | دنبال‌کردن/لغو؛ خودفالو ممنوع |
| members/CODE/ | GET | نام، آواتار و آمار عمومی حساب فعال |
| rankings/ | GET | رده‌بندی حلقه‌ها با ضریب ۲ حضور و امتیاز مربی |
| profile/status/, profile/avatar/ | PUT | وضعیت/آواتار خود عضو |
| files/upload/PURPOSE/ | POST | avatar، proof یا post؛ محدودیت فایل و سهمیه |
| files/ID/ | GET | کنترل مالکیت/نقش؛ proof خصوصی، پیوست فقط اگر پست قابل مشاهده باشد |
| messages/ | POST | مربی: scope برابر all/group/ring/person و target مربوط |
| messages/read/ | POST | علامت‌گذاری پیام‌های خود عضو |
| grades/ring/, grades/group/ | PUT | مربی؛ target و score |
| oversight/ | GET | مربی؛ metric، person، ring، team؛ گزارش هفت روز اخیر |
| notices/read/ | POST | اعلان‌های خود عضو |
| assistant/chat/ | POST | message؛ آمار خود/حلقه، راهنما، احوالپرسی |
| landing/, forms/ | POST | مسئول کارگروه؛ محتوای همان کارگروه |
| forms/ID/answers/ | PUT, GET | ثبت پاسخ خود؛ خواندن پاسخ‌ها فقط سازندهٔ فرم/مربی |
| admin/members/ | POST | ادمین؛ ایجاد عضو با اعتبارسنجی رمز |
| admin/members/CODE/roles/ | PUT | ادمین؛ تغییر نقش و عضویت؛ حفاظت آخرین ادمین |
| admin/members/CODE/suspend/ | POST | ادمین؛ days برابر ۱ یا ۳ |
| admin/reports/ | GET | ادمین؛ تعداد شب ثبت، افراد بدون ثبت و برنامه/جلسه‌های هفته |
| health/ | GET | سلامت درخواست و دیتابیس |

گزارش هفتگی ادمین از شنبهٔ هفتهٔ جاری در منطقهٔ زمانی تهران محاسبه می‌شود. رشد خصوصی حتی برای ادمین از state دیگران برگردانده نمی‌شود؛ مربی مسیر مجاز نظارت فردی دارد. مواردی مانند SQL خام، code نویسنده، نقش یا مسیر دلخواه فایل از ورودی کاربر قابل تزریق نیستند.

کدهای رایج: ۴۰۰ ورودی نامعتبر، ۴۰۱ ورود اشتباه، ۴۰۳ عدم دسترسی/CSRF/تعلیق، ۴۰۴ مورد ناموجود، ۴۰۹ کد تکراری، ۴۱۳ فایل بزرگ، ۴۲۹ محدودیت درخواست، ۵۰۳ اختلال وابستگی. درخواست‌ها retry نوشتنی خودکار ندارند؛ گزارش روزانه و رأی‌ها قابلیت تکرار امن دارند. ثبت پست/دیدگاه/پیام عملیات ایجاد است و retry دستی می‌تواند رکورد جدید ایجاد کند.
